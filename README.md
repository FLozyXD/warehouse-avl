# Warehouse AVL — складской учёт на AVL-деревьях

Консольная система учёта товаров на складе. Каждое поле товара индексируется
собственным AVL-деревом, поэтому поиск по ID, названию, категории, цене и
остатку работает за `O(log n)`, а диапазонные запросы — без полного перебора.

Учебный проект по структурам данных: собственная реализация AVL-дерева,
обёртки типов, диапазонный поиск и сравнение с несбалансированным BST.

## Возможности

- Добавление, удаление и редактирование товаров.
- Поиск по точному значению: ID, название, категория, цена, количество.
- Диапазонные запросы: цена «от и до», количество, префикс названия или
  категории.
- Отчёт по товарам ниже минимального остатка.
- Табличный вывод каталога.
- Загрузка и сохранение CSV (`assortment.csv`, UTF-8 с BOM).
- Бенчмарк AVL против обычного BST.
- 9 модульных тестов.

## Стек

- Python 3.10+
- Стандартная библиотека (`csv`, `enum`, `unittest`)
- Собственные структуры данных, без pandas и ORM

```text
main.py              консольное меню
ext/

tests.py             unittest
assortment.csv       демонстрационный каталог
IDEAS.md             заметки о развитии проекта
```

### Как устроена индексация

`InventorySystem` держит по одному `Bank` на каждое поле. `Bank` оборачивает
`AVLTree` и умеет:

- `get(value)` — точный поиск;
- `get_range(start, end)` — поиск в полуинтервале.

Для префиксного поиска по названию используется диапазон
`[prefix, prefix + chr(0x10FFFF))`: все строки с нужным началом попадают в
него лексикографически.

`Property` хранит значение и ссылки на товары, поддерживает приведение типов
и валидацию (неотрицательные числа), а `Product` — слоты для экономии памяти.

## Запуск

```bash
python main.py
```

Меню:

```text
0 — общий отчёт
1 — добавить товар
2 — удалить товар
3 — обновить количество
4 — поиск по названию (префикс)
5 — поиск по категории
6 — поиск по диапазону цен
7 — отчёт по запасам
8 — сохранить и выйти
```

Изменения сохраняются в `assortment.csv` при выходе.

## Тесты

```bash
python -m unittest -v
```

## Сложность

| Операция | AVL | BST (среднее) | BST (худшее) |
|---|---|---|---|
| Поиск | `O(log n)` | `O(log n)` | `O(n)` |
| Вставка | `O(log n)` | `O(log n)` | `O(n)` |
| Удаление | `O(log n)` | `O(log n)` | `O(n)` |
| Диапазон | `O(log n + k)` | `O(log n + k)` | `O(n)` |

- Проектирование составных индексов без внешней СУБД.
